# Bash To-Do List Manager

A simple and interactive To-Do List manager built with Bash scripting.

## Features

- View tasks
- Add tasks
- Delete tasks
- Persistent storage using `~/todo.txt`

## Run the Script

```bash
chmod +x todo.sh
./todo.sh
```
